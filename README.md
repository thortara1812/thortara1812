## 💡 Featured Projects

Here are some of the projects I've worked on across Artificial Intelligence, Machine Learning, Deep Learning and Software Development.

### 🩸 RedLink – AI-Powered Blood Donation Optimization Platform

An AI-powered platform designed to optimize blood donor discovery and improve the efficiency of blood donation coordination.

- Intelligent donor matching and prioritization.
- Machine Learning-based prediction and optimization.
- Location-aware donor discovery.
- Application development using Python and database technologies.

**Technologies:** Python · Machine Learning · LightGBM · XGBoost · MongoDB · FastAPI

### 📚 InclusiveVerse AI – Intelligent Learning Platform

An AI-powered educational platform designed to make learning more accessible and personalized.

- AI-powered lecture summarization.
- Document-based Retrieval-Augmented Generation (RAG) chatbot.
- Automated quiz and flashcard generation.
- Adaptive learning and weak-topic identification.
- Lecture transcription and learning progress dashboard.

**Technologies:** Python · Streamlit · Generative AI · RAG · SQLite · PyTorch

### 🏥 MedIR-X – Medical Information Retrieval System

A domain-specific information retrieval project focused on improving access to relevant medical information.

- Medical document processing and retrieval.
- Search and information organization.
- Relevance-based information discovery.
- Structured medical information presentation.

**Technologies:** Python · Information Retrieval · NLP · Machine Learning



### 🌐 Network Traffic Anomaly Detection

A Machine Learning project focused on identifying anomalous network traffic using the CICIDS2017 dataset.

- Network traffic preprocessing.
- Autoencoder-based anomaly detection.
- Representation learning and anomaly identification.
- Model evaluation.

**Technologies:** Python · Deep Learning · PyTorch · Autoencoders · CICIDS2017
